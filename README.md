# Mazua Safaris 🦁

A safari and tourism website developed for Mazua Safaris using Python and Django.

## 🌍 Live Website

https://mazuasafari.pythonanywhere.com

## 📖 About the Project

Mazua Safaris is a web application designed to help visitors explore safari services and contact the business about bookings. This project marks my first client project and another milestone in my journey as a developer.

## ✨ Features

- Responsive website for visitors
- Booking request and customer communication functionality
- Email notifications for booking inquiries, where configured
- Django administration panel
- Contact links for communication with the business

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- Git and GitHub

## 🎯 Project Goals

- Apply Python and Django to a real-world client project
- Develop practical web development and deployment skills
- Build useful digital solutions for businesses
